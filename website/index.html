FAQ

常见问题

需要注册或激活吗？
不需要。安装后即可使用，不需要账号、激活码、设备绑定或远程授权。
支持哪些大模型？
历史配置兼容 DeepSeek、Kimi、智谱、通义、Gemini、Claude 等 provider。新增模型时只提供 APINest 和自定义，自定义接口填写 OpenAI 兼容地址与 Key 即可。
设置的主题，重启 Codex 后还在吗？
在的。主题通过后台守护线程自动注入并持久化，Codex 启动、重启甚至更新后都会自动恢复，无需重复设置。
会收集我的数据吗？
不会。Codex助手是本地适配器，所有请求从本机直接转发到你配置的模型服务商，不经过第三方中转；配置、Key 和用量统计均保存在本机。
支持哪些系统版本？
macOS 支持 Apple Silicon 与 Intel 两种架构（.dmg 原生安装包），Windows 支持 10 / 11，另有免安装便携版，解压即用。
如何更新到新版本？
客户端不访问远程版本服务器。请从项目发布页下载最新安装包，直接覆盖安装或替换便携版即可。
和 OpenAI Codex 官方客户端冲突吗？
不冲突。Codex助手 只是把 Codex 的请求转发到你选择的大模型服务商，切换前后都会自动备份 Codex 配置，随时可以一键还原回官方设置。
