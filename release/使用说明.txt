============================================
  Codex助手 -- 使用手册
============================================

这个程序可以让你的 OpenAI Codex App 改用 DeepSeek、Kimi、智谱、通义
等任意 OpenAI 兼容的国产/海外大模型，一键切换，不用换 Codex 客户端。

============================================
【准备一次性工作】

1. 装好 OpenAI Codex App（已经在用就行）
2. 去你要用的模型平台注册账号、充值、复制 API Key：
     - DeepSeek:  https://platform.deepseek.com
     - Kimi:      https://platform.moonshot.cn
     - 智谱 GLM:  https://open.bigmodel.cn
     - 阿里通义:  https://dashscope.console.aliyun.com
     - 其他自查
   每家的 Key 都长这样：sk- 开头的一长串字符

============================================
【启动用法】

第 1 步：双击 Codex助手.app
   - 第一次启动可能慢 5-10 秒（正常，在初始化）
   - 如果 macOS 提示"无法验证开发者"-> 系统设置 -> 隐私与安全 -> 仍要打开

第 2 步：在窗口里
   - 点击「模型配置」按钮
   - 选择服务商和模型，粘贴对应平台的 API Key
   - 保存后回到首页
   - 点开关按钮启动服务
   - 界面显示"运行中"就行了

第 3 步：打开 Codex App
   - Codex 现在已经在用你选的模型
   - 重要：Codex助手窗口不要关，关了就连不上适配器

============================================
【加更多模型（自定义提供商）】

在「模型配置」页面点「新增模型」：

  - 服务商下拉：内置多个常用平台模板（智谱/通义/小米MIMO/Kimi/
    StepFun/LongCat/Claude/Gemini 等），选了自动填好 Base URL
  - 选择对应模型
  - 填入 API Key
  - 保存即可

不在模板里的模型？服务商选「自定义」，全手填：
  - 模型名称：去那家文档查（如 glm-4-plus / qwen-max）
  - Base URL：去那家文档查 chat/completions 完整端点
  - API Key：那家给你的 sk- 开头字符串

已添加的模型可以随时编辑或删除。

============================================
【不用了，想切回 OpenAI】

   - 点开关按钮停止服务
   - 会自动恢复 OpenAI 原始配置
   - 重启 Codex App 生效

============================================
【日常使用】

   - 每次想用别的模型：打开 Codex助手 -> 选模型 -> 开关按钮启动
   - 想切回 OpenAI：开关按钮停止 -> 关窗口
   - Key 会按厂商分开记住，下次自动加载，不用重输

============================================
【出问题怎么办】

▸ 双击没反应
  -> 等 10 秒，第一次启动慢
  -> macOS 安全限制：系统设置 -> 隐私与安全 -> 仍要打开

▸ Codex 报连接失败
  -> Codex助手窗口关了，重新打开它

▸ Codex 报 401 / Invalid API Key
  -> 该平台的 API Key 错了或余额没了，去对应平台查

▸ Codex 报 unknown model / 404
  -> 自定义条目里的"模型名称"写错了，去那家文档对一下
  -> 或者 Base URL 不对，确认末尾是 /chat/completions

▸ Codex 还显示 OpenAI / GPT
  -> 彻底退出 Codex 再重开

▸ 想彻底卸载
  -> 删 Codex助手.app
  -> 适配器之前帮你备份了 Codex 原配置在：
    ~/.codex/config.toml.openai-backup
  -> 把这个 .openai-backup 文件复制为 config.toml（覆盖）就回到原状

============================================
【安全说明】

  - 所有 API Key 只保存在你本机的临时目录中
  - 适配器只在本机 127.0.0.1:18667 监听，外网访问不到
  - 第一次切换时会自动备份你原 Codex 配置，不会覆盖丢失
  - API Key 只发往你选的那家上游 API，不发往任何第三方
